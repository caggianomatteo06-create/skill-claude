# skill claude

Questo repository contiene lo skill Claude Code **volantini-linea**.

## Cosa contiene

- [`volantini-linea.skill`](volantini-linea.skill) — pacchetto dello skill (archivio zip) che permette a Claude di creare in Canva i volantini promozionali mensili di Linea S.r.l. (distribuzione alimentare, Asti), riproducendo lo stile storico dell'azienda: intestazione, banner fornitore, schede prodotto e footer legale.

## Come si usa

Lo skill viene invocato automaticamente da Claude quando l'utente chiede di creare, aggiornare o rifare un volantino mensile, le offerte del mese o una promozione su articoli per Linea S.r.l.
